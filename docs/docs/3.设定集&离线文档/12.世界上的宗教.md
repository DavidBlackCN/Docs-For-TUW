## ==世界守望者的六项戒律==
:::

---

::: window title="世界守望者的六项戒律"
我（指守望者）教你们扶着戒律对我发誓，使我能度量其言行的真伪：

壹：凡信我（指守望者）的，你们的地位都是平等的，
不得杀害我的同胞，奴役我的子民。
你们不要想，我是叫地上的人太平；我来并不只是叫地上太平。乃是叫地上动刀兵。


贰：我（指守望者）将赐予你们宝藏，宝藏被深深埋藏。
远古的文字是我赐予的提示，腐朽的古书是我的嘱咐。
我的宝藏只有被好好保护，才能教你们解放世人的灵魂，洗涤污浊的本性。
才能在地上叫人变成鬼的旧社会死亡，建立起使鬼变成人的至福的国。


叁：我（指守望者）教你对我的子民用双手捧上善心，让罪恶唾弃在你的脚下。
是教你领会我在天国的意，传福音给穷人，使我可以看到：
使贫穷的得以被教育、瞎眼的得以看得见、叫那些受压制的得以自由。
从而在我解放的新社会里享精神的至福。


肆：我（指守望者）必临近你们，施行审判。我必速速作见证，警戒行邪术的、
犯奸淫的、起假誓的、亏负人工钱的、欺压寡妇孤儿的、屈枉寄居的，和不敬畏我的。


伍：凡信我（指守望者）的，你必须始终清醒，
教你带被异端引诱的我的子民回我（指守望者）的身下，
放弃为他的神雕刻偶像，在天国享受至福与光辉。


陆：我（指守望者）的名必须避讳，我的名不可被妄称，
更不能被亵渎。我将用风雨，用闪电，对亵渎者施以惩罚。
:::
